# Style guide

- Language: 中文工作底稿与中文论文；除非作者另行要求，不生成英文主稿
- Target reader: 概率论、网络系统与区块链交叉审稿人
- Tone: scientific-question-driven，保守但明确
- Canonical title term: 首次余额耗尽时间 / first balance-depletion time
- Canonical object: multi-party payment channel represented as a hyperedge
- Empirical method name: frozen v4 asymptotically constrained crossover approximation
- Preferred verbs: 证明（仅限完整证明）、导出（代数/生成元结果）、数值支持、经验验证、提示
- Forbidden expressions: 通用闭式、首次、完全解决、严格误差界、网络死亡、全维度证明、黑箱之外的“理论保证”（若只有拟合）、“三人乘积闭式是本文新定理”、“一般多人 Poisson 方程由本文首次提出”、“公平随机选对多人模型由本文提出”、“四人单纯形/Brownian 近似由本文首次提出”、“FCLT + 连续映射 + Feynman--Kac 本身构成主要创新”、“内部对抗式审计等同外部独立核查”
- Audit wording: “内部对抗式证明审计”只表示项目内从定义重推并主动寻找反例；只有未参与当前推导的概率论研究者复核后，才使用“外部独立核查通过”。
- Number policy: 同一表格精度一致；误差报告同时给样本量、参数域和区间方法
- Statistical stance: 先报告效应/误差分布与不确定性，再报告阈值通过率
- Citation style: 投稿前按目标期刊统一；内部文档保留 DOI/arXiv 直链
- Supervisor preferences: AUTHOR_INPUT_NEEDED

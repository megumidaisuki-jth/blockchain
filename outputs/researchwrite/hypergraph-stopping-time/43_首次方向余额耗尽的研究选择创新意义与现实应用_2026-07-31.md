# 首次方向余额耗尽：研究选择、创新意义与现实应用

> 整理日期：2026-07-31
> 对应研究：《原子路由下超图支付通道网络的首次耗尽时间》
> 文档性质：关于停止事件选择、学术创新性与现实用途的集中说明

## 1. 核心结论

当前研究选择“网络内部第一次出现方向余额耗尽”，不是因为它等同于现实中的首次支付失败，而是因为它是一个仅由余额状态和原子路由增量决定、能够被严格定义为随机过程首次退出的结构性流动性边界。首次触零本身属于经典边界命中问题，论文的创新不在于提出“触零”这个概念，而在于围绕该停止事件建立了同时包含超图余额守恒、跨通道原子依赖、漂移尺度相图和独立聚合误差的统一理论与实验框架。

现实中，该停止时间更适合作为方向流动性瓶颈的领先风险指标，可用于容量规划、路由策略压力测试、再平衡预警、拓扑设计和独立通道风险模型审计；它不能被直接解释为真实 Lightning 网络的首次失败、通道关闭或网络死亡时间。

## 2. 术语与时间索引

| 术语 | 本文含义 |
|---|---|
| 首次方向余额耗尽时间 \(\tau_N\) | 任一方向余额在一笔已接受的单位原子支付执行后首次达到 0 的时间 |
| 首次余额型拒绝时间 \(\rho_{\rm bal}\) | 某个支付请求在执行前首次因方向余额不足而被拒绝的时间 |
| 首次请求不可服务时间 \(\rho_{\rm req}\) | 在给定请求、金额、路由和协议规则下，首次不存在可行支付路径的时间 |
| 原子路由 | 同一笔端到端支付同步更新所有经过通道的路由语义 |
| 独立通道边际代理 | 保留每条通道完整的一步边际分布，但删除同一步跨通道联合依赖的统计对照 |
| 方向流动性瓶颈 | 某个支付方向的可用余额达到预设边界；它不意味着整个网络停止服务 |

## 3. 为什么研究首次触零，而不是直接研究首次支付不可用

### 3.1 两个停止事件并不相同

当前论文定义

\[
\tau_N=
\inf\left\{
n\ge 0:
\min_i X_{N,i}^{\rm free}(n)=0
\right\},
\]

其中时间单位是已接受的单位原子支付笔数。该事件只由初始余额、路由序列和余额增量决定。

“首次支付不可用”则必须同时知道下一笔请求的源节点、目的节点、金额、可选路径、路由算法、费用、通道储备、HTLC 状态、重试规则以及是否允许多路径支付。它不是单纯由当前余额状态决定的统一事件。

| 比较维度 | 首次方向余额触零 | 首次支付不可用 |
|---|---|---|
| 主要决定因素 | 余额状态与原子路由增量 | 余额、请求、金额、路径、算法与协议约束 |
| 是否为状态过程的固定边界 | 是 | 通常不是 |
| 是否能写成乘积单纯形首次退出 | 是 | 需要扩展状态后重新定义 |
| 是否直接对应现实失败 | 否 | 在协议和请求定义完整时可以 |
| 当前定理能否直接适用 | 可以 | 不能原样适用 |

### 3.2 触零的那笔支付仍然是可执行的

假设第 \(n\) 笔支付执行前所有所需方向余额严格为正，其中一个方向余额为 1。单位支付执行后，该余额从 1 降为 0，于是 \(n=\tau_N\)。但这笔支付执行前仍满足余额条件，因此它先被接受，执行后才触零。

在理想单位模型中，只要有限的首次余额型拒绝存在，就有

\[
\rho_{\rm bal}>\tau_N.
\]

通常不能进一步写成

\[
\rho_{\rm bal}=\tau_N+1,
\]

因为下一笔请求可能不使用触零方向，可能通过其他路径绕行，也可能由反向支付恢复该方向余额。

项目已经对这一时间索引进行确定性穷举：在两个双向通道、6 条单位路由、\(N=1,2,3\) 和长度 6 请求序列的设计中，共检查 139,968 个规模—序列案例，观察到 110,308 个触边案例和 71,688 个有限余额拒绝案例，没有发现 \(\rho_{\rm bal}\le\tau_N\) 的违例。同时找到了三类具体证人：

1. 触零后下一笔同方向请求立即被拒绝；
2. 策略条件可以在余额触零前拒绝请求；
3. 反向支付可以恢复已经触零的方向，使观察窗内不再出现余额拒绝。

因此，首次触零与首次拒绝的区别是由事件发生位置和请求条件决定的，而不是符号约定。

### 3.3 “支付不可用”本身存在多种定义

如果直接把研究对象改成“首次支付不可用”，至少需要在以下定义中作出选择：

- 指定路由第一次不可用；
- 某个给定源宿对第一次不存在可行路径；
- 路由算法完成全部尝试后第一次失败；
- 任意候选路径都无法承载某一金额；
- 第一笔随机请求失败；
- 全网不再能够完成任何支付；
- 一段时间内支付成功率低于预设阈值。

这些定义产生不同的停止时间。例如，路由算法选择了一条余额不足的路径，并不意味着网络中不存在其他可行路径；某个大额支付失败，也不意味着小额支付不可执行；某个方向触零，也不意味着不使用该方向的请求失败。

若要建立请求级停止时间，可以令第 \(n\) 个外生请求为

\[
R_n=(s_n,t_n,a_n),
\]

并令 \(\mathcal P(R_n,X(n-1))\) 表示在执行前状态 \(X(n-1)\) 下满足余额、费用和协议条件的可行路径集合。一个严格定义是

\[
\rho_{\rm req}
=
\inf\left\{
n\ge1:
\mathcal P(R_n,X(n-1))=\varnothing
\right\}.
\]

但使用该定义必须同时冻结请求过程、支付金额、路由选择、费用、储备、替代路径和重试规则，还必须区分“所有请求的时间”与当前论文使用的“已接受支付的时间”。现有五个定理不能未经修改直接套用。

### 3.4 首次触零为何适合作为理论主事件

选择 \(\tau_N\) 有五个直接理由：

1. 它是状态过程本身的停止时间，不依赖下一笔请求的具体属性。
2. 它恰好对应乘积单纯形的边界，能够建立有限状态吸收 Markov 链和 Poisson 方程。
3. 它支持函数型中心极限定理、Brownian 首次退出和漂移三分区证明。
4. 它隔离了余额耗尽机制，避免把路由算法、支付金额和协议策略同时混入核心定理。
5. 它为不同拓扑、需求核和依赖结构提供统一、可比较的流动性压力指标。

因此，当前选择是一个有意收窄的理论设计：先解决能够严格闭合的方向流动性边界，再明确说明它与请求级支付失败之间的距离。

## 4. 研究首次方向余额耗尽是否具有创新意义

### 4.1 创新不在“触零”概念本身

随机游走触边、赌徒破产和首次退出时间均已有成熟理论。如果论文只研究单条独立通道何时到达 0，创新性会比较有限。当前工作的贡献来自把这一经典停止事件放入新的网络结构和比较问题中，并完成此前分散要素之间的连接。

更准确的创新表述是：

> 本研究在固定超图支付通道网络中，以跨通道原子路由产生的联合余额增量为基础，建立首次方向余额耗尽的有限状态方程、漂移尺度相图和独立边际代理比较，并通过严格生存序、有限容量反例和公开拓扑实验共同界定独立聚合的适用范围。

### 4.2 四个主要创新层次

#### 4.2.1 统一网络建模

多方通道被表示为余额守恒超边，整个状态空间是多个守恒单纯形的笛卡尔积。一笔原子支付可以同步更新多条超边，从而在同一个随机过程中保留：

- 多方通道内部余额守恒；
- 多跳支付的同步更新；
- 路由重叠造成的跨通道联合依赖；
- 任一方向余额首次耗尽的网络级停止事件。

该建模避免把原子端到端支付事后拆成互不相关的单通道事件。

#### 4.2.2 容量—漂移尺度理论

研究把需求不平衡写成容量相关漂移

\[
d_N\asymp N^{-\alpha},
\]

并证明首次耗尽时间具有三种尺度：

\[
\tau_N\asymp
\begin{cases}
N^{1+\alpha},&0\le\alpha<1,\\
N^2,&\alpha=1,\\
N^2,&\alpha>1.
\end{cases}
\]

其中 \(\alpha=1\) 是漂移与扩散同时保留的临界点；\(\alpha>1\) 时漂移在 \(N^2\) 时间尺度消失。证明不仅给出分布收敛，还通过统一指数矩闭合全部固定正阶矩收敛。

#### 4.2.3 可解释的独立聚合误差

论文构造独立通道边际代理：每条通道单独观察到的一步分布完全不变，只删除同一步跨通道联合结构。由此可以回答：

> 当单通道统计完全相同时，忽略原子路由依赖会把网络首次耗尽时间估高还是估低？

在平衡、严格零漂移、固定有限二元通道的 Gaussian 极限中，中心对称安全域与 Gaussian 相关不等式给出相关模型不短于独立代理的极限生存序；当跨块 Gaussian 协方差为 0 时，又可严格恢复逐通道生存函数乘积。

#### 4.2.4 正向定理、有限反例与现实形状诊断共同限定结论

三节点路径在 \(N=1\) 时给出精确反例

\[
\Delta_1=-0.125,
\]

说明 Gaussian 极限非负序不能加强为所有有限容量的逐点结论。三类高阶拓扑的 36 个冻结单元均呈正效应，而 2020—2026 年 Lightning 公开拓扑和热点需求又出现正负并存与符号反转。

这些结果共同支持的不是“相关性永远有利”，而是：

> 相关效应的符号取决于初态、漂移、安全域几何、容量和原子联合路由；独立聚合必须在这些条件下接受检验。

## 5. 现实中的具体应用

### 5.1 通道容量规划

停止时间尺度能够判断增加容量带来的实际寿命收益。若需求存在不随容量减弱的固定方向偏差，即 \(\alpha=0\)，则

\[
\mathrm E\tau_N\asymp N.
\]

此时容量翻倍只能带来约线性的首次耗尽时间增长。如果错误采用公平随机游走的 \(N^2\) 规律，就可能把容量翻倍解释为寿命约增至四倍，从而高估扩容效果。

因此，容量设计不应只看通道总容量，还应同时估计需求漂移及其随容量的变化。

### 5.2 再平衡预警与干预时机

现实系统通常不会等到方向余额真正为 0 才采取行动，而会设置安全阈值。可以把研究对象自然扩展为

\[
\tau_{\rm warn}
=
\inf\left\{
n:
X_i(n)\le r_i+a_{\min}
\text{ for some active direction }i
\right\},
\]

其中 \(r_i\) 是不可使用的储备或安全余额，\(a_{\min}\) 是系统希望继续支持的最小支付金额。

首次触零理论可以作为阈值模型的基准，用于估计：

- 多久需要执行循环再平衡；
- 哪个方向最可能首先成为瓶颈；
- 应保留多少方向流动性；
- 在给定风险容忍度下应何时触发干预。

固定储备边界可以通过状态平移转化为触零边界；随机金额、动态费用和余额感知策略则需要进一步扩展。

### 5.3 路由策略压力测试

不同路由策略会产生不同的漂移 \(d_N\)、协方差 \(\Gamma_N\) 和跨通道联合结构。可以在相同拓扑和需求下比较最短路、随机分流、流动性均衡路由、热点规避路由和多路径路由，并评价：

- 平均首次耗尽时间；
- 首次耗尽时间分位数；
- 在目标期限内提前耗尽的概率；
- 最容易耗尽的方向；
- 独立聚合估计与原子联合模型之间的偏差。

当前理论适合对固定的外生路由策略进行离线比较。如果路由概率根据实时余额自适应变化，则过程变为状态依赖模型，需要重新建立相应定理。

### 5.4 独立通道风险模型审计

网络级风险模型经常先计算各通道的生存概率，再假设独立并作乘积。当前研究提供了三类审计依据：

1. Gaussian 极限跨块协方差为 0 时，独立乘积具有严格充分条件；
2. 受控高阶拓扑中，独立代理可能系统性低估首次耗尽时间；
3. 极小容量和热点需求下，独立代理也可能高估首次耗尽时间。

因此，该框架可用于检查支付通道模拟器、容量规划工具或风险分析程序是否因错误独立化而产生方向性偏差。

### 5.5 热点需求与流动性集中诊断

在固定八个 Lightning 拓扑锚点的需求插值实验中，需求从均匀分布向高连接度目的节点集中时，相关效应整体下降并形成有限设计上的符号分离。这表明拓扑不变并不意味着联合耗尽风险不变；支付目的地集中会同时改变漂移、协方差和更高阶路由依赖。

实际用途包括：

- 识别容易形成单向流动性积压的枢纽；
- 比较普通转账与商户集中场景；
- 判断节点需要增加入站还是出站流动性；
- 评估新增高流量目的节点对邻近通道的压力；
- 判断历史均匀需求模型是否低估热点风险。

该实验只能支持固定公开拓扑和合成需求下的结构性诊断，不能据此估计真实 Lightning 支付失败率。

### 5.6 多方通道和高阶拓扑设计

超图模型可以比较链式、星形和分支式多方通道结构，考察共享参与者和跨超边路由如何改变首次耗尽。潜在用途包括：

- 识别容易产生共同瓶颈的高阶连接；
- 比较不同多方通道布置的流动性耐久性；
- 评估共享节点是否放大跨通道依赖；
- 为通道工厂、虚拟通道或未来多方支付结构提供压力测试方法。

当前高阶结果是有限设计证据，不构成任意高阶超图的统一生存序。

### 5.7 精确求解器和模拟器基准

小容量 Poisson 方程、\(N=1\) 精确反例以及 \(N=2\) 高阶拓扑精确锚点可作为模拟器测试基准，用于发现：

- 状态枚举错误；
- 原子路由被错误拆分；
- 独立代理未保持通道边际；
- 停止时间索引偏移；
- Monte Carlo 实现或归一化错误。

这类基准不直接解决运营问题，但能够提高后续路由、容量和再平衡实验的可信度。

## 6. 现实意义的边界

首次方向余额耗尽是领先风险指标，不是网络死亡时间。某个方向触零后：

- 其他通道仍可能继续工作；
- 不经过该方向的请求仍可完成；
- 替代路径可能绕开瓶颈；
- 反向支付可能恢复方向余额；
- 协议条件也可能在触零之前造成支付失败。

此外，公开 Lightning 拓扑不包含真实方向余额、支付尝试、失败码、重试和再平衡日志。因此，当前公开拓扑实验可以说明独立聚合误差如何受拓扑和需求影响，但不能预测某个现实节点或通道还能工作多久。

首次“任一方向”触零还是一个偏保守的极值指标。在大型网络中，一个几乎没有需求的边缘方向触零，实际影响可能很小。若面向运营部署，后续可以研究：

- 仅在活跃需求支持集上定义首次耗尽；
- 使用储备和支付金额阈值替代数学上的 0；
- 定义首次关键源宿对不可服务；
- 定义支付成功率首次低于服务水平阈值；
- 使用第 \(k\) 个瓶颈时间或需求加权耗尽指标，降低单个边缘方向的支配作用。

## 7. 最合适的论文定位

当前研究最有说服力的问题不是：

> 网络什么时候第一次支付失败？

而是：

> 在固定路由和需求机制下，网络多久会首次形成方向流动性瓶颈；忽略跨通道原子依赖，会怎样误判这一时间？

建议论文统一使用以下表述：

- 使用“首次方向余额耗尽”“首次流动性边界命中”或“首次方向流动性瓶颈”；
- 不把 \(\tau_N\) 简写为现实网络“首次失败时间”；
- 把独立代理称为统计对照，而不是可执行路由协议；
- 把 Lightning 实验称为公开拓扑上的结构性或机制性验证；
- 把再平衡、容量规划和路由压力测试写成潜在应用，而不是已经部署的系统功能。

可以用于论文创新性说明的集中表述是：

> 本研究并不把首次方向余额耗尽等同于现实支付失败，而是将其定义为原子路由下可严格分析的网络流动性边界。在此基础上，本文统一刻画有限网络精确均值、容量相关漂移尺度以及跨通道依赖造成的独立聚合偏差，并通过严格生存序、有限容量反例、高阶拓扑实验和公开 Lightning 拓扑诊断共同界定结论的适用范围。

## 8. 结论

研究网络内部第一次出现方向余额耗尽具有明确的学术意义和实际价值，但价值来自对停止事件的正确定位。它不是现实支付不可用的同义词，而是一个能够隔离余额耗尽机制、支持严格概率分析并为流动性管理提供预警基准的结构性事件。

在数学层面，当前工作把经典触边问题扩展到超图守恒状态、跨通道原子路由和容量相关漂移环境，并建立独立聚合误差的条件性生存序；在应用层面，它能够服务于容量规划、再平衡阈值、路由策略压力测试、热点需求诊断和风险模型审计。与此同时，论文必须持续保留三条边界：首次触零不等于首次失败，高阶有限设计不等于普遍定理，公开拓扑模拟不等于真实支付数据校准。
